# Retail Business Analytics Project

End-to-end portfolio project demonstrating SQL, Power BI/DAX, business requirements and process analysis.

### Business problem
Management needs a centralized view of sales performance across products, customers, stores and regions. The existing manual reporting process is slow and difficult to analyse.

### Objectives
- Monitor revenue, profit and orders
- Identify top/underperforming products
- Analyse customers and regions
- Track performance over time
- Recommend an automated BI reporting process

### Tools
Power BI, DAX, SQL, Excel/CSV, BPMN, GitHub.

### Contents
- `Data/retail_sales.csv` — 8,000 synthetic transactions
- `SQL/analysis_queries.sql` — SQL analysis examples
- `PowerBI/` — DAX and dashboard specification
- `Documentation/` — requirements, user stories and process analysis

> Portfolio simulation using synthetic data; no real company data is represented.
